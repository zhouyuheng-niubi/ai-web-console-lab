# 应急预案完整结构编写指南

本指南涵盖综合应急预案、专项应急预案、现场处置方案及附件的完整编写技能体系。

## 一、综合应急预案编写技能（依据GB/T29639-2020）

- **总则编写技能**：能严格遵循GB/T29639-2020标准，清晰界定综合应急预案的适用范围，明确覆盖的事故类型、区域及岗位；科学划分应急响应等级，依据事故危害程度、影响范围和企业控制能力明确分级原则，杜绝照搬事故分级，确保总则贴合标准、兼具合规性与实用性。

- **应急组织机构及职责编写技能**：可规范设计应急组织形式（可配套图示），明确各构成单位（部门）的应急处置职责；合理设置应急工作小组，细化各小组的构成、职责分工及行动任务，并按要求将小组工作方案作为附件，确保组织架构清晰、权责分明、符合标准规范。

- **应急响应编写技能**：能全面覆盖信息报告、预警、响应启动、应急处置、应急支援、响应终止全流程，明确各环节的操作程序、责任人和核心要求；规范信息接报与研判流程，合理设置预警启动与解除机制，精准调整响应级别，确保应急响应有序、高效、贴合实际。

- **后期处置编写技能**：可针对事故后续恢复需求，明确污染物处理、生产秩序恢复、人员安置的具体措施和流程，确保后期处置全面、规范，推动事故后各项工作有序回归正常。

- **应急保障编写技能**：能围绕通信信息、应急队伍、物资装备及其他保障（能源、经费、医疗等），明确各项保障的具体内容、责任人和配套措施，建立物资装备台账，同时按要求将相关保障内容纳入附件，确保应急保障无遗漏、可落地。

## 二、专项应急预案编写技能（标准格式）

- **适用范围编写技能**：能严格按照专项预案标准格式，清晰界定预案适用的事故类型、场景及岗位，同时明确与综合应急预案的衔接关系，说明两者配合逻辑，确保适用边界清晰、衔接顺畅。

- **应急组织机构及职责编写技能**：可规范编写应急组织形式（可配套图示），明确各构成单位（部门）及相关人员的具体应急职责；若设置应急工作小组，可将小组构成、职责分工及行动任务以工作方案形式作为附件，确保组织架构规范、权责清晰。

- **响应启动编写技能**：能明确响应启动后的程序性工作，包括应急会议召开、信息上报、资源协调、信息公开、后勤及财力保障等，细化各环节操作要求，确保响应启动后各项工作有序推进。

- **处置措施编写技能**：可结合专项事故风险特点，明确应急处置指导原则，针对事故风险、危害程度和影响范围，制定针对性、可操作的应急处置措施，确保措施贴合专项场景、能有效控制事态。

- **应急保障编写技能**：能根据专项应急工作需求，明确核心保障内容，涵盖通信、队伍、物资、经费等，确保保障措施全面、有针对性，支撑专项应急处置有序开展。

## 三、现场处置方案编写技能（标准格式）

- **事故风险描述编写技能**：能简要阐述事故风险评估结果，清晰梳理核心风险点、危害程度及影响范围；若需详细呈现，可按要求将风险评估结果以列表形式作为附件，确保风险描述简洁、精准、贴合现场实操。

- **应急工作职责编写技能**：可明确现场应急组织的分工及具体职责，清晰划分各岗位、各人员的职责边界，避免职责交叉或遗漏，贴合现场处置的即时性、协同性需求。

- **应急处置编写技能**：能规范编写应急处置程序，明确事故报警、应急措施启动、救护人员引导、事故扩大处置及与企业整体预案的衔接流程；同时从人员救护、工艺操作、事故控制、消防、现场恢复等维度，制定具体、可操作的现场处置措施。

- **报警与报告编写技能**：能明确报警负责人、报警电话，以及上级管理部门、相关应急救援单位的联络方式和联系人；规范事故报告的基本要求和核心内容，确保报警及时、报告规范。

- **注意事项编写技能**：可全面梳理现场处置的注意事项，涵盖人员防护与自救互救、装备使用、现场安全等核心内容，规避处置过程中的安全隐患，确保现场处置安全、规范。

## 四、应急预案附件编写技能（标准格式）

- **基础信息类附件编写技能**：能规范编写生产经营单位概况、风险评估结果，简要呈现单位核心信息、风险分布及等级，为应急预案落地提供基础支撑；同时清晰说明预案体系构成、分级情况及与外部预案的衔接关系，可配套图示辅助。

- **保障支撑类附件编写技能**：可规范编制应急物资装备名录，明确物资装备的名称、型号、数量、存放地点、管理责任人等信息，建立完整台账；全面梳理应急联络方式，确保应急相关部门、人员的联系方式齐全、畅通。

- **实操辅助类附件编写技能**：能编写信息接报、预案启动、信息发布等格式化文本，确保应急文书规范统一；全面梳理关键路线、标识和图纸，包括警报系统、疏散路线、单位地理位置、医院路线等，为现场处置提供直观指引。

- **联动协议类附件编写技能**：可列出与相关应急救援部门签订的应急救援协议或备忘录，明确协议核心内容，确保应急联动有依据、有保障，提升应急支援效率。

## 五、应急预案整体适配与标准化编写技能

- **结构衔接编写技能**：能确保综合预案、专项预案、现场处置方案及附件之间逻辑连贯、衔接顺畅，明确各层级预案的定位和配合关系，形成完整的应急预案体系，符合GB/T29639-2020标准要求。

- **标准化与实操性平衡技能**：可严格对照标准格式，确保各模块内容、顺序、要求合规，杜绝偏离标准、遗漏核心条款；同时贴合企业生产经营实际，细化操作标准，突出现场处置的实操性和附件的实用性，确保预案可直接用于企业应急管理工作。
