# 应急预案编写技能规则

本目录包含应急预案编写的详细技能规则，用于指导不同类型预案的规范化编写。

## 文件说明

| 文件名 | 适用预案类型 | 核心内容 |
|--------|--------------|----------|
| `04-cover-and-front-matter-guide.md` | 封面及前置文档 | 封面格式、编制小组成立通知、发布实施令、执行部门签署页等红头文件编写 |
| `01-comprehensive-plan-guide.md` | 综合应急预案 | 依据GB/T29639-2020标准编写总则、组织机构、应急响应、后期处置、应急保障 |
| `02-special-and-site-plan-guide.md` | 专项应急预案<br>现场处置方案<br>附件 | 标准格式编写：适用范围、组织机构、响应启动、处置措施、风险描述、应急职责、注意事项 |
| `03-complete-structure-guide.md` | 全套预案体系 | 综合+专项+现场+附件的完整结构编写技能，各级预案衔接与标准化 |

## 使用建议

### 按预案类型选择
- **编写封面及前置文档** → 参考 `04-cover-and-front-matter-guide.md`
- **编写综合应急预案** → 参考 `01-comprehensive-plan-guide.md`
- **编写专项应急预案** → 参考 `02-special-and-site-plan-guide.md` 第一部分
- **编写现场处置方案** → 参考 `02-special-and-site-plan-guide.md` 第二部分
- **编写预案附件** → 参考 `02-special-and-site-plan-guide.md` 第三部分
- **编写全套预案体系** → 参考 `03-complete-structure-guide.md`

### 与模板的关系
- **规则文件**（本目录）：提供编写方法、结构要求、标准规范
- **模板文件**（templates/目录）：提供具体事故类型的内容示例

### 编写流程
1. 根据预案类型选择对应的规则文件
2. 先生成封面及前置文档（封面、编制小组成立通知、发布实施令、执行部门签署页）
3. 根据事故类型选择templates/中的具体模板
4. 结合规则要求 + 模板内容 → 生成完整预案

## 标准依据

- GB/T 29639-2020《生产经营单位生产安全事故应急预案编制导则》
- 应急预案标准格式要求
