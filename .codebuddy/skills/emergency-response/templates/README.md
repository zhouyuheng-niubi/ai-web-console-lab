## 使用说明

### 1. 选择模板
根据事故类型选择对应模板：
- **火灾事故** → Fire and Evacuation Emergency Plan.md
- **危险化学品泄漏** → Hazardous Chemical Leak Emergency Plan.md
- **触电事故** → Electric Shock Emergency Plan.md
- **灼烫伤害** → Burn Injury On-site Emergency Disposal Plan.md
- **高处坠落** → High-altitude Fall On-site Emergency Disposal Plan.md
- **机械伤害** → Mechanical Injury On-site Emergency Disposal Plan.md
- **粉尘爆炸** → Dust Explosion Injury On-site Emergency Disposal Plan.md
- **职业病危害** → Occupational Hazard (Dust, Noise) Injury On-site Emergency Disposal Plan.md
- **其他事故** → 根据具体类型选择对应模板

### 2. 提取信息
从用户需求中提取：
- 预案名称
- 企业类型（化工/机械/建筑/矿山/服务业）
- 事故类型（火灾/泄漏/触电/机械伤害等）
- 当前已有内容

### 3. 填充内容
根据模板结构，结合企业类型和事故类型的特点，填充具体内容。

### 4. 生成输出
将填充后的内容按Word格式HTML输出。

## 不同类型企业适配要点

### 化工企业
- **重点事故类型**：危险化学品泄漏、火灾爆炸、中毒窒息、灼烫
- **强调**：泄漏处置、中毒急救、环境监测、防爆防护

### 机械制造企业
- **重点事故类型**：机械伤害、触电、物体打击、灼烫
- **强调**：设备急停、断指保存、安全防护、现场急救

### 建筑施工企业
- **重点事故类型**：高处坠落、坍塌、起重伤害、物体打击
- **强调**：高处救援、坍塌搜救、临边防护、触电防护

### 矿山企业
- **重点事故类型**：瓦斯爆炸、透水、冒顶片帮、中毒窒息
- **强调**：井下救援、通风系统、监测预警、粉尘控制

### 服务业企业
- **重点事故类型**：火灾、电梯困人、人员踩踏、触电
- **强调**：人员疏散、消防管理、客流控制、特种设备安全

### 涉及粉尘作业企业
- **重点事故类型**：粉尘爆炸、尘肺病、火灾
- **强调**：防爆措施、通风除尘、职业病防护

### 涉及高温作业企业
- **重点事故类型**：高温中暑、灼烫、火灾
- **强调**：防暑降温、热害防护、应急救援
