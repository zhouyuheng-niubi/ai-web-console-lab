- 加粗：`<b>文字</b>` 或 `<strong>文字</strong>`
- 下划线：`<u>文字</u>`
- 高亮：`<span style="background-color: #FFFF00">文字</span>`
- 红色警示：`<span style="color: #FF0000">文字</span>`
- 操作卡边框：`<div style="border: 2pt solid #000; padding: 12pt; margin: 12pt 0;">...</div>`

### 报告生成格式细则

生成应急预案报告时，必须严格遵守以下格式规范：

#### 1. 报告标题
- 使用 `<p>` 标签包裹，字体采用黑体加粗，必须居中显示
- 报告标题根据用户提供的预案名称确定，如"生产安全事故综合应急预案"

#### 2. 报告日期
- 固定在报告标题下方，统一格式为"报告日期：YYYY年MM月DD日"
- 居中显示，字体为小四（12pt）宋体，西文/数字用 Times New Roman

#### 3. 标题层级格式
| 标题级别 | 字体 | 字号 | 对齐方式 | 段前/段后间距 | 其他 |
|---------|------|------|---------|--------------|------|
| 报告标题 | 黑体 | 22pt | 居中 | 24pt/24pt | 加粗 |
| 一级标题 | 黑体 | 16pt | 左对齐 | 18pt/12pt | 加粗，底部边框1pt |
| 二级标题 | 黑体 | 14pt | 左对齐 | 12pt/8pt | 加粗 |
| 三级标题 | 黑体 | 12pt | 左对齐 | 8pt/6pt | 加粗 |

#### 4. 文档整体格式
- **中文字体**：宋体
- **西文/数字字体**：Times New Roman
- **正文字号**：小四（12pt）
- **行距**：1.5倍
- **段落间距**：段前6pt，段后6pt
- **对齐方式**：全文两端对齐（标题、报告日期除外）
- **段落首行缩进**：2字符（标题、报告日期、表格内容除外）

#### 5. 其他规则
- 报告结尾禁止出现报告单位、"以上报告"等收尾表述
- 数据需要排列清晰，确保可以一眼看清、一目了然，无任何格式错误
- 图表信息需配备适当的标题和说明文字，确保图表与正文内容相符
- 数据表格需要表头清晰，数据对齐，确保可读性

#### 6. AI 自验证强制流程
生成报告后，必须按以下步骤自动校验格式，确保完全符合要求：

| 校验项 | 校验内容 |
|--------|---------|
| 标签校验 | 检查报告标题是否用 `<p>` 标签包裹且居中，无多余标签或缺失标签 |
| 标题层级校验 | 逐一核对各级标题的字体、字号、加粗状态、对齐方式及段前段后间距 |
| 文本格式校验 | 随机抽取3处正文段落，检查字体、字号、行距、段落间距、首行缩进及对齐方式；检查所有西文/数字是否使用 Times New Roman 字体 |
| 图表表格校验 | 确认所有图表都有对应的标题和说明文字；检查数据表格表头完整，数据对齐正确 |
| 整体兼容性校验 | 确保HTML代码可直接在Word中打开，格式不错乱 |
| 数据排列校验 | 确保所有数据排列清晰，确保可以一眼看清、一目了然，无任何格式错误 |

#### 7. 输出要求
- 最终以 HTML 格式输出完整报告
- 输出内容仅包含 HTML 代码
- style 绑定的属性样式都需添加 `!important`
- 无任何格式说明、注释等额外文字
- 确保代码可直接复制使用且格式100%符合上述规范

## 工作流指令

当用户请求生成应急预案时，按以下步骤执行：

### 步骤1：提取关键信息
从用户输入中提取以下内容：
- **预案名称**：如"火灾事故专项应急预案"、"危险化学品泄漏现场处置方案"等
- **预案类型**：综合预案 / 专项预案 / 现场处置方案
- **事故类型**：火灾 / 泄漏 / 触电 / 机械伤害 / 高处坠落 / 中毒窒息 / 坍塌等
- **企业类型**：化工 / 机械制造 / 建筑施工 / 矿山 / 服务业等
- **当前内容**：用户提供的现有内容或需要补充的要点

### 步骤2：选择对应模板
根据事故类型选择 `templates/` 目录下的模板文件：

#### 专项应急预案（二级）

| 事故类型 | 模板文件 | 适用场景 |
|----------|----------|----------|
| 火灾/疏散 | `Fire and Evacuation Emergency Plan.md` | 火灾事故及人员疏散 |
| 危险化学品泄漏 | `Hazardous Chemical Leak Emergency Plan.md` | 危化品泄漏事故 |
| 触电 | `Electric Shock Emergency Plan.md` | 触电伤害事故 |
| 锅炉压力容器 | `Boiler and Pressure Vessel Emergency Plan.md` | 特种设备爆炸/泄漏 |
| 电梯困人/坠落 | `Elevator Injury Emergency Plan.md` | 电梯安全事故 |

#### 现场处置方案（三级）

| 事故类型 | 模板文件 | 适用场景 |
|----------|----------|----------|
| 灼烫伤害 | `Burn Injury On-site Emergency Disposal Plan.md` | 热力/化学灼烫 |
| 粉尘爆炸 | `Dust Explosion Injury On-site Emergency Disposal Plan.md` | 粉尘爆炸伤害 |
| 乙醇泄漏 | `Ethanol Leak Injury On-site Emergency Disposal Plan.md` | 乙醇等化学品泄漏 |
| 高温中暑 | `High Temperature Heatstroke Injury On-site Emergency Disposal Plan.md` | 高温作业中暑 |
| 高处坠落 | `High-altitude Fall On-site Emergency Disposal Plan.md` | 高处作业坠落 |
| 机械伤害 | `Mechanical Injury On-site Emergency Disposal Plan.md` | 机械设备伤害 |
| 物体打击 | `Object Strike On-site Emergency Disposal Plan.md` | 物体打击伤害 |
| 职业病危害 | `Occupational Hazard (Dust, Noise) Injury On-site Emergency Disposal Plan.md` | 粉尘/噪声职业危害 |
| 中毒 | `Poisoning Injury On-site Emergency Disposal Plan.md` | 有毒有害物质中毒 |
| 车辆伤害 | `Vehicle Injury On-site Emergency Disposal Plan.md` | 厂内机动车辆伤害 |

### 步骤3：参考编写规则
根据预案类型，参考 `rules/` 目录下的编写指南：

| 预案类型 | 参考规则文件 | 核心内容 |
|----------|--------------|----------|
| 封面及前置文档 | `04-cover-and-front-matter-guide.md` | 封面格式、编制小组成立通知、发布实施令、执行部门签署页 |
| 综合应急预案 | `01-comprehensive-plan-guide.md` | GB/T29639-2020标准：总则、组织机构、应急响应、后期处置、应急保障 |
| 专项应急预案 | `02-special-and-site-plan-guide.md` 第一部分 | 标准格式：适用范围、组织机构、响应启动、处置措施、应急保障 |
| 现场处置方案 | `02-special-and-site-plan-guide.md` 第二部分 | 标准格式：风险描述、应急职责、应急处置、注意事项 |
| 预案附件 | `02-special-and-site-plan-guide.md` 第三部分 | 标准格式：单位概况、风险评估、物资清单、联系方式、图纸等 |
| 全套预案体系 | `03-complete-structure-guide.md` | 综合+专项+现场+附件完整结构及各层级衔接 |

### 步骤4：生成Word格式HTML
按以下要求生成最终输出：
1. 使用上方"输出格式规范"中的HTML模板
2. 根据**封面及前置文档编写指南**生成封面、编制小组成立通知、发布实施令、执行部门签署页
3. 根据所选**规则文件**确定文档结构和条款要求
4. 根据所选**模板文件**填充具体事故类型的内容
5. 使用表格、列表等格式清晰呈现
6. 确保样式符合Word文档标准

## 技能模块框架

应急预案文档通常包含以下核心模块（根据预案类型选择适配）：

| 模块类别 | 说明 |
|----------|------|
| 预案体系 | 四级架构：综合预案、专项预案、现场处置方案、附件 |
| 应急组织 | 指挥层、应急办、各专项小组（疏散、抢险、后勤、通讯、医疗等） |
| 风险分析 | 企业类型风险评估、事故类型分析、危险源辨识 |
| 预警机制 | 监测内容、预警分级、发布流程、响应措施 |
| 应急响应 | 响应分级、报告时限、处置流程、扩大响应条件 |
| 事故处置 | 各类事故（火灾、泄漏、触电、机械伤害等）的操作卡 |
| 应急保障 | 物资、装备、通信、医疗、经费、外部资源联动 |
| 培训演练 | 培训对象/内容/频次、演练类型/评估/整改 |
| 后期处置 | 污染物处理、现场清理、生产恢复、事故调查、善后处理 |

> **说明**：各模块的具体内容根据企业类型、事故类型、预案类型进行定制化生成。

### C. 关键操作要点

**灭火器使用**：提→拔→握→压（对准火苗根部喷射）

**心肺复苏**：评估→通畅气道→人工呼吸→胸外按压（30:2比例，深度5-6cm）
